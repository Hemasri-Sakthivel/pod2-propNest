PropNest — IAM API
Postman Testing Guide

Complete request / response reference and a recommended testing order for all 15 Identity & Access Management endpoints.

SettingValue
Base URLhttp://localhost:8082/propNest/IAM
Auth schemeAuthorization: Bearer <accessToken> on every protected endpoint
Access token lifetime30 minutes
Refresh token lifetime7 days
Content-Typeapplication/json on every request that has a body

Prerequisite: the app must be running (mvnw spring-boot:run) with MySQL up on localhost:3306. The 6 roles are auto-seeded on startup.

1. Postman Setup (recommended)

1.1 Create an Environment with these variables

VariableInitial value
baseUrlhttp://localhost:8082/propNest/IAM
adminToken(leave empty — filled by tests)
adminRefreshToken(empty)
userToken(empty)
userRefreshToken(empty)
tenantUserId(empty)

1.2 Auto-capture tokens

On the admin Login request, add this to the Scripts → Post-response tab so the token is stored automatically:

const json = pm.response.json();
pm.environment.set("adminToken", json.accessToken);
pm.environment.set("adminRefreshToken", json.refreshToken);

On the normal user Login request use:

const json = pm.response.json();
pm.environment.set("userToken", json.accessToken);
pm.environment.set("userRefreshToken", json.refreshToken);

Then in protected requests set the header Authorization: Bearer {{adminToken}} (or {{userToken}}).

2. Recommended Testing Order

Roles exist at startup, but no users do. So you must register an admin first, then everything flows from the tokens you obtain.

StepEndpointWhy this order
1POST /auth/register (roleId 6 = REAL_ESTATE_ADMIN)Create the admin account
2POST /auth/login (admin)Get adminToken + adminRefreshToken
3GET /admin/rolesConfirm seeded roles / get valid roleIds
4GET /users/meRead admin's own profile
5PUT /users/meUpdate admin name/phone
6POST /admin/users (roleId 2 = TENANT)Admin onboards a tenant → note its userId
7GET /admin/usersList all users (try ?role= / ?status=)
8GET /admin/users/{userId}Read the tenant by id
9PUT /admin/users/{userId}/roleReassign tenant's role
10PUT /admin/users/{userId}/statusSuspend / reactivate tenant
11POST /auth/register (roleId 2) or login as the tenantGet a non-admin userToken
12GET /admin/users with {{userToken}}Expect 403 (role enforcement check)
13PUT /users/me/password (as tenant)Change own password
14POST /auth/login (tenant, new password)Confirm password change works
15POST /auth/refresh-tokenMint a fresh access token
16GET /admin/audit-logSee all recorded actions
17GET /admin/audit-log/user/{userId}See one user's actions
18POST /auth/logoutRevoke the refresh token
19POST /auth/refresh-token (same token)Expect 401 (token revoked)

3. Endpoint Reference

Legend: public authenticated REAL_ESTATE_ADMIN only

1. POST /auth/register   public

Headers: Content-Type: application/json

Request Body:

{
  "name": "Admin User",
  "email": "admin@propnest.com",
  "phone": "9876500000",
  "password": "Admin@123",
  "roleId": 6
}

201 Created:

{ "message": "User registered successfully" }

Errors: 400 (invalid input / unknown roleId), 409 (email already registered)

{ "status": 409, "message": "Email already registered: admin@propnest.com",
  "path": "/propNest/IAM/auth/register", "timestamp": "2026-06-16T10:30:00Z" }

roleId values: 1=OWNER, 2=TENANT, 3=PROPERTY_MANAGER, 4=TECHNICIAN, 5=FINANCE_EXECUTIVE, 6=REAL_ESTATE_ADMIN

2. POST /auth/login   public

Headers: Content-Type: application/json

Request Body:

{
  "email": "admin@propnest.com",
  "password": "Admin@123"
}

200 OK:

{
  "accessToken": "eyJhbGciOiJIUzI1Ni...",
  "refreshToken": "k3p9aZ...url-safe-random...",
  "userId": 1,
  "role": "REAL_ESTATE_ADMIN"
}

Errors: 400 (missing email/password), 401 (wrong credentials, or account not active)

{ "status": 401, "message": "Invalid email or password",
  "path": "/propNest/IAM/auth/login", "timestamp": "..." }

3. POST /auth/logout   authenticated

Headers: Content-Type: application/json · Authorization: Bearer {{adminToken}}

Request Body:

{ "refreshToken": "{{adminRefreshToken}}" }

200 OK:

{ "message": "Logged out successfully" }

Errors: 401 (missing/expired access token)

4. POST /auth/refresh-token   refresh token

Headers: Content-Type: application/json

Request Body:

{ "refreshToken": "{{adminRefreshToken}}" }

200 OK:

{ "accessToken": "eyJhbGciOiJIUzI1Ni..." }

Errors: 401 (refresh token expired, revoked after logout, or unknown)

{ "status": 401, "message": "Refresh token expired or revoked",
  "path": "/propNest/IAM/auth/refresh-token", "timestamp": "..." }

5. GET /users/me   authenticated

Headers: Authorization: Bearer {{adminToken}} · Body: none

200 OK:

{
  "userId": 1,
  "name": "Admin User",
  "email": "admin@propnest.com",
  "phone": "9876500000",
  "role": "REAL_ESTATE_ADMIN",
  "status": "A"
}

Errors: 401 (missing/expired token)

6. PUT /users/me   authenticated

Headers: Content-Type: application/json · Authorization: Bearer {{adminToken}}

Request Body:

{
  "name": "Admin Updated",
  "phone": "9876511111"
}

200 OK:

{ "message": "Profile updated successfully" }

Errors: 400 (blank name, or phone not 10-15 digits), 401

Only name and phone can be changed here. Email and role cannot.

7. PUT /users/me/password   authenticated

Headers: Content-Type: application/json · Authorization: Bearer {{userToken}}

Request Body:

{
  "currentPassword": "Tenant@123",
  "newPassword": "NewPass@456"
}

200 OK:

{ "message": "Password changed successfully" }

Errors: 400 (current password incorrect, or new password < 8 chars), 401

{ "status": 400, "message": "Current password is incorrect",
  "path": "/propNest/IAM/users/me/password", "timestamp": "..." }

8. POST /admin/users   REAL_ESTATE_ADMIN only

Headers: Content-Type: application/json · Authorization: Bearer {{adminToken}}

Request Body:

{
  "name": "Ravi Kumar",
  "email": "ravi@propnest.com",
  "phone": "9123456789",
  "password": "Tenant@123",
  "roleId": 2
}

201 Created:

{ "message": "User created successfully" }

Errors: 400 (invalid input / unknown roleId), 401, 403 (not admin), 409 (email exists)

Tip: capture the created user's id by calling GET /admin/users?role=TENANT and saving tenantUserId for the next steps.

9. GET /admin/users   REAL_ESTATE_ADMIN only

Headers: Authorization: Bearer {{adminToken}}

Optional query params: ?role=TENANT   ?status=A   ?role=TENANT&status=A

Example: GET {{baseUrl}}/admin/users?role=TENANT&status=A

200 OK:

{
  "users": [
    {
      "userId": 2,
      "name": "Ravi Kumar",
      "email": "ravi@propnest.com",
      "phone": "9123456789",
      "role": "TENANT",
      "status": "A"
    }
  ]
}

Errors: 400 (invalid status; allowed A, I, S), 401, 403

Post-response script to save the tenant id (when filtering to one user):

const u = pm.response.json().users[0];
if (u) pm.environment.set("tenantUserId", u.userId);

10. GET /admin/users/{userId}   REAL_ESTATE_ADMIN only

Headers: Authorization: Bearer {{adminToken}}

Example: GET {{baseUrl}}/admin/users/{{tenantUserId}}

200 OK:

{
  "userId": 2,
  "name": "Ravi Kumar",
  "email": "ravi@propnest.com",
  "phone": "9123456789",
  "role": "TENANT",
  "status": "A"
}

Errors: 401, 403, 404 (no user with that id)

{ "status": 404, "message": "User not found with id: 999",
  "path": "/propNest/IAM/admin/users/999", "timestamp": "..." }

11. PUT /admin/users/{userId}/status   REAL_ESTATE_ADMIN only

Headers: Content-Type: application/json · Authorization: Bearer {{adminToken}}

Request Body:

{ "status": "S" }

Allowed values: A = Active, I = Inactive (soft-delete), S = Suspended.

200 OK:

{ "message": "User status updated successfully" }

Errors: 400 (invalid status value), 401, 403, 404

A suspended (S) or inactive (I) user can no longer log in (login returns 401). Set it back to A to re-enable login.

12. PUT /admin/users/{userId}/role   REAL_ESTATE_ADMIN only

Headers: Content-Type: application/json · Authorization: Bearer {{adminToken}}

Request Body:

{ "roleId": 3 }

200 OK:

{ "message": "User role updated successfully" }

Errors: 400 (unknown roleId), 401, 403, 404

13. GET /admin/roles   REAL_ESTATE_ADMIN only

Headers: Authorization: Bearer {{adminToken}}

200 OK:

{
  "roles": [
    { "roleId": 1, "roleName": "OWNER" },
    { "roleId": 2, "roleName": "TENANT" },
    { "roleId": 3, "roleName": "PROPERTY_MANAGER" },

    { "roleId": 6, "roleName": "REAL_ESTATE_ADMIN" }

14. GET /admin/audit-log   REAL_ESTATE_ADMIN only

Headers: Authorization: Bearer {{adminToken}}

200 OK (most recent first):

{
  "logs": [
    { "auditId": 5, "userId": 2, "action": "USER_ROLE_UPDATED", "entityType": "USER", "timeStamp": "2026-06-16T10:40:12Z" },
    { "auditId": 1, "userId": 1, "action": "USER_REGISTERED",   "entityType": "USER", "timeStamp": "2026-06-16T10:30:00Z" }
  ]
}

Errors: 401, 403

Recorded actions: USER_REGISTERED, USER_LOGIN, USER_LOGOUT, TOKEN_REFRESHED, PROFILE_UPDATED, PASSWORD_CHANGED, USER_CREATED, USER_STATUS_UPDATED, USER_ROLE_UPDATED.

15. GET /admin/audit-log/user/{userId}   REAL_ESTATE_ADMIN only

Headers: Authorization: Bearer {{adminToken}}

Example: GET {{baseUrl}}/admin/audit-log/user/{{tenantUserId}}

200 OK:

{
  "logs": [
    { "auditId": 5, "userId": 2, "action": "USER_ROLE_UPDATED", "entityType": "USER", "timeStamp": "2026-06-16T10:40:12Z" },
    { "auditId": 3, "userId": 2, "action": "USER_CREATED",      "entityType": "USER", "timeStamp": "2026-06-16T10:35:00Z" }
  ]
}

Errors: 401, 403, 404 (no user with that id)

4. Quick Error-Code Cheat Sheet

CodeMeaningTypical trigger
200 OKSuccessGET / PUT / login / refresh / logout
201 CreatedCreatedregister, admin create user
400 Bad RequestInvalid inputvalidation failure, invalid roleId, invalid status, wrong current password
401 UnauthorizedNot authenticatedmissing/expired/invalid token, bad login, revoked refresh token
403 ForbiddenWrong roleauthenticated but not REAL_ESTATE_ADMIN on an admin endpoint
404 Not FoundMissing resourceunknown userId on admin user / audit-log lookups
409 ConflictDuplicateduplicate email
500 Server ErrorServer faultunexpected error

All error bodies share this shape:

{ "status": 401, "message": "...", "path": "/propNest/IAM/...", "timestamp": "2026-06-16T10:30:00Z" }
